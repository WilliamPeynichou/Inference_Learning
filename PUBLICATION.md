# Publication Preparation

## Before archiving

- [ ] Confirm author name, optional affiliation, publication date, and version.
- [x] Licenses chosen: CC BY 4.0 for original study text, figures, and data; MIT for scripts. Third-party rights are excluded; see [LICENCES.md](LICENCES.md).
- [ ] Confirm personal 30-day aggregate exports may be archived publicly. They do not contain conversations but are personal usage data.
- [ ] Document exact dates and harness, Prime, and model versions where known.
- [ ] Recover ARC-AGI-3 pilot traces and resolve the discrepancy concerning first-trial tools. If unavailable, retain the qualification and identify the report as preliminary.
- [ ] Check rights to third-party names, games, screenshots, and other material. No third-party screenshots are intentionally included.
- [ ] Review the report and any LinkedIn draft; do not claim token savings are measured by these exports.

## GitHub and Zenodo

The public GitHub repository can be connected to Zenodo before creating a study release, or an archive can be deposited manually. Review scope and licenses first: an archived version should be treated as durably accessible.

Zenodo assigns a version DOI and a concept DOI. Prefer citing the precise version DOI; add the assigned DOI and public URL to the README and citation metadata after publication. A DOI provides a persistent reference, not peer review or scientific validation.

## Portfolio

Link a concise summary to the study and, when available, its DOI. Preserve figure captions and limitations. SVGs are standalone but browser rendering depends on available fallback fonts.
